# Откуда скилл и что в нём своё

Копия `skills/security-audit/` и `LICENSE` (MIT) из
https://github.com/cloudflare/security-audit-skill, коммит `c1c8a8c`
(2026-09-14). Своё — только шапка `SKILL.md`:

- `disable-model-invocation: true` — Claude Code не грузит скилл сам, только
  по `/security-audit` или прямому указанию прочесть `SKILL.md`. Иначе
  широкое исходное описание («security questions, focused reviews…»)
  срабатывало бы на каждое «ревью безопасности» в задаче.
- описание переписано так, чтобы и Codex, Gemini, OpenCode (флаг они не
  знают) не брали его для обычного ревью диффа.

Обновить: скопировать новую версию поверх, вернуть эту шапку, поправить
коммит здесь, прогнать `node validate-findings.test.cjs` и
`node validate-coverage-ledger.test.cjs`.

## Как запускать

Руками в проекте: `/security-audit full audit, profile quick` (или
`standard`, `deep`). По расписанию — расписание Paseo с промптом:

> Прочитай ~/.claude/skills/security-audit/SKILL.md и выполни full audit
> mode этого репозитория, профиль quick, без бюджета. Выходной каталог —
> по умолчанию скилла. Вопросов не задавай: режим и профиль заданы.
> Код проекта не запускай — песочницы, которую требует скилл, здесь нет;
> то, что без запуска не подтвердить, оставляй needs_validation.
> Ход не заканчивай до конца аудита. Субагентов хук велит запускать в
> фоне — запускай, но жди их сам на переднем плане (Monitor или опрос
> их выходных файлов), а не уведомления: в Paseo оно может не прийти.
> Задания охотникам и проверяющим можно класть в файлы и велеть прочесть
> — 50 КБ дословных блоков в вызов не помещаются. Живое состояние хоста
> читать можно, менять — нет.
> В конце одной строкой: путь к REPORT.md и число confirmed по серьёзности.

Для самого vps-dev добавить к промпту модель доверия: машина одного
владельца, пользователь dev равен root, действие владельца — не находка.
У проектов с пользователями и арендаторами этого не писать.

Прогоны складываются: каждый пишет в `~/security-audit-skill/<repo>/run-N`,
следующий читает прежние `coverage-ledger.json` и добирает пропущенное.
