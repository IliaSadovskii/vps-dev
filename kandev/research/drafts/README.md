# Черновики промптов

Здесь лежат промпты, написанные ИИ одним заходом для пробных цепочек
`feature` / `research` / `small-fix`, которые удалены. Они не вычитаны и не
одобрены — держим их только как образец для сравнения, пока пишем настоящие
роли. Когда роли будут готовы, каталог можно удалить.

Из `kandev/prompts/` они убраны намеренно: роль `seed` заливает в Kandev всё,
что лежит там, и эти восемь висели бы в списке сохранённых промптов рядом с
похожими по имени настоящими ролями — `custom-implement` рядом с
`custom-implementation`, `custom-verify` рядом с `custom-verification`.
