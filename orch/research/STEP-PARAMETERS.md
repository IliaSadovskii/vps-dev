# Параметры шага цепочки

Собрано 2026-09-05 из: Kandev (11 триггеров, поля шага — `kandev/research/
PLATFORM-CAPABILITIES.md`), OpenAI Symphony (`WORKFLOW.md`: `max_turns`,
`turn_timeout_ms`, `stall_timeout_ms`, хуки рабочего пространства,
concurrency по состояниям, retry с backoff), сабагентов Claude Code
(`tools`/`disallowedTools`, `model`, `permissionMode`, `maxTurns`, `skills`,
`mcpServers`, `hooks`, `effort`, `isolation: worktree`, `memory`), режимов
Kilo/Roo (`roleDefinition`, `whenToUse`, `groups` с `fileRegex`),
Temporal (четыре таймаута и retry policy), GitHub Actions (`needs`, `if`,
`timeout-minutes`, `continue-on-error`, `environment` с ревьюерами и
таймером ожидания, `concurrency`).

Колонка «AoE» — чем реализуется: **ACP** — параметр сессии AoE, **движок**
— наш код поверх событий AoE, **промпт** — только текстом роли, **нет** —
пока недостижимо.

## A. Кто работает

| Параметр | Смысл | AoE | v1 |
|---|---|---|---|
| `agent` | claude / codex / opencode | ACP | да |
| `model` | модель этого агента | ACP | да |
| `effort` | усилие рассуждения | ACP | да |
| `mode` | права: `bypassPermissions` / `acceptEdits` / `default` / `plan` | ACP | да |
| `tools.deny` | запретить инструменты (например, Write на ревью) | через настройки агента в worktree (`.claude/settings.json`), не на сессию; для Codex нет | позже |
| `mcp` | какие MCP-серверы дать, кроме `orch` | глобальный `mcp.json`, на сессию нельзя | позже |
| `include` | файлы, вклеиваемые в промпт (навыки, конвенции, `AGENTS.md`) | движок собирает промпт | да |
| `sandbox` | запустить в контейнере | ACP | позже |
| `env` | переменные окружения сессии | ACP `extra_env` | да |

## B. Что делает и чем отчитывается

| Параметр | Смысл | AoE | v1 |
|---|---|---|---|
| `prompt` | файл роли | движок | да |
| `instructions` | добавка к роли именно в этой цепочке (как сейчас «Колонка сейчас: …») | движок | да |
| `reads` | что роли можно читать из артефактов (матрица входов из контракта) | промпт + проверка MCP `read_artifact` | да |
| `writes` | какой артефакт обязан появиться, обязательные разделы | движок проверяет перед переходом, иначе отказ в `step_complete` с причиной | да |
| `signal` | переход только по явному `orch_step_complete` (как `auto_advance_requires_signal`) | движок | да, всегда |
| `check` | команда после хода: тесты, линтер, скрипт владения тестами; ненулевой код → исход `failed` | движок, команда в worktree | да |
| `report` | должен ли шаг оставить раздел «Для владельца» (перед воротами) | движок проверяет | да |

## C. Память

| Параметр | Смысл | AoE | v1 |
|---|---|---|---|
| `context` | `fresh` (новая сессия, знает только файлы) / `continue` (промпт в сессию предыдущего шага) / `fork` (копия разговора предыдущего шага, только Claude) | ACP: новая сессия / `acp/prompt` / `fork_from` | да |
| `continue_from` | чью сессию продолжать, если не предыдущего шага | движок | позже |
| `inject` | что вклеить в первый промпт: текст задачи, заметки владельца адресату, выбранный вариант, список «не решено» | движок | да |
| `on_return` | при возврате в шаг: `same_session` (та же сессия помнит прошлый заход) / `fresh` | движок | да |

## D. Переходы

| Параметр | Смысл | AoE | v1 |
|---|---|---|---|
| `next` | куда по умолчанию после `step_complete` | движок | да |
| `outcomes` | именованные исходы шага → цель: `clean → draft-pr`, `findings → review-fixes`, `failed → implementation`. Роль называет исход в `step_complete(outcome=…)` | движок | да |
| `returns_to` | куда роль может вернуть сама; список, обычно один шаг | движок | да |
| `return_budget` | сколько автовозвратов на заход (сейчас 1; заход открывает заметка человека) | движок | да |
| `gate` | ворота человека: `forward`, `back` (список допустимых), `default_addressee` заметок, `options_from` (исходы из раздела «Что решить») | движок + панель | да |
| `gate.auto_after` | авто-принятие через N минут без ответа (уровень автономии) | движок | да |
| `gate.auto_when` | авто-принятие по условию: нет находок, вердикт `clean` | движок | позже |
| `manual_entry` | можно ли человеку двинуть задачу сюда кнопкой (список из `PROCESS.md`) | движок + панель | да |
| `skip_if` | пропустить шаг: нет входа (артефакт пуст), метка задачи, размер диффа | движок | позже (сейчас это делает роль прыжком) |

| Параметр | Смысл | AoE | v1 |

## J. Уровень цепочки

| Параметр | Смысл | v1 |
|---|---|---|
| `autonomy` | `manual` (все ворота ждут) / `gates_auto` (ворота проходят сами через `auto_after`) / `full` (плюс вопросы агента получают ответ «решай сам») | да |
| `context_blocks` | границы общей памяти, выводятся из `context` шагов | да |
| `worktree` | `per_task` (одна ветка на задачу, все сессии в ней) / `none` (в основном каталоге) / `base_branch` | да |
| `routes` | Quick / Standard / Deep как наборы `skip` над одной цепочкой, а не три файла | позже |
| `on_done` | запустить другую цепочку с текстом задачи из артефакта | позже |
| `budget` | предел стоимости задачи | позже |
| `includes` | общие промпты для всех шагов (контракт артефактов, git-safety) | да |

## Что даёт AoE бесплатно и не надо описывать

Восстановление сессии после перезапуска, очередь промптов в занятую
сессию, сторожевые таймеры зависшего хода внутри одного хода, парк по
лимиту провайдера с авто-возобновлением (`rate_limit_auto_resume`), пуш на
телефон, форма вопроса `AskUserQuestion`, одобрения инструментов,
worktree на ветку, дифф и комментарии к нему.
