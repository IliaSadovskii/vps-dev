# 001. Пересечения броней запрещает база, не код

Дата: 2026-09-11 · Статус: принято

**Решено.** Ограничение `EXCLUDE USING gist (room_id WITH =, tstzrange(starts_at, ends_at) WITH &&) WHERE (status <> 'cancelled')` в миграции. В коде проверки пересечений нет.

**Почему.** Две проверки (код и база) расходятся; гонку двух запросов ловит только база. Ошибку базы действие переводит в текст формы.

**Отвергли.** Проверка в `SaveBooking` с блокировкой строки комнаты: работает, но дублирует то, что база делает сама, и не защищает от прямой записи.

**Где.** `database/migrations/*_create_bookings_table.php`, `tests/Feature/Bookings/OverlapTest.php`.
