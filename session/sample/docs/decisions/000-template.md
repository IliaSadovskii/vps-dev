# NNN. Название решения

Дата: ГГГГ-ММ-ДД · Статус: принято

**Решено.** Одна-две строки: что делаем.

**Почему.** Две-четыре строки: довод, который перевешивает.

**Отвергли.** Варианты и по строке, чем не подошли.

**Где.** Ссылка на код, тест или документ, где решение видно.

**Проверка.** Арх-тест, тест или скрипт, который поймает нарушение; «ревью» — только по слову владельца.
