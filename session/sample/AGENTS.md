# Переговорки

Бронирование переговорных комнат внутри одной компании: сотрудник видит
свободные комнаты и бронирует слот, офис-менеджер ведёт комнаты. Один
арендатор, один часовой пояс, вход по корпоративной почте.

## Проверить себя, поднять проект

| Что | Команда |
|---|---|
| Поднять / погасить | `make up` / `make down`; порт — `ports which rooms` |
| Тесты | `make test`; узко: `docker compose exec app ./vendor/bin/pest tests/Feature/Bookings/CreateBookingTest.php` |
| Линт и формат | `make lint`; поправить формат `make fix` |
| Всё перед PR | `make check` |
| Логи, письма | `make logs`; письма в Mailpit после `make up-all` |
| Глазами | `make front`, открыть в браузере; UI без открытия не проверен |

## Когда остановиться и спросить

- схема БД, публичный контракт (внешний API, событие домена, формат экспорта — не маршрут страницы), новая зависимость, необратимая миграция;
- красный тест после одного круга починки — стоп, в отчёт; тест не трогать;
- тест утверждает неверное — сказать, не переписывать;
- проект не решил или решил по-разному в разных местах — развилка: спросить, не выбирать ближайшее;
- спрашивать до конца хода, с вариантами, пока можно перестроить под ответ.

## Продукт

- Кому: сотрудникам (бронируют) и офис-менеджеру (ведёт комнаты). Внешних пользователей нет. Роль — поле `role` у пользователя, на него смотрят политики.
- Что: комната, слот, бронь. Одна бронь — одна комната — один непрерывный слот. Повторяющихся броней нет (`docs/decisions/002-bez-povtorov.md`).
- Готово, когда: сотрудник за минуту находит свободную комнату на нужное время и бронирует; две брони на один слот невозможны на уровне базы; отмена и перенос не теряют историю.
- Не продукт: гости, оплата, интеграция с календарями кроме экспорта `.ics`.
- Сценарии — `docs/scenarios.md`.

## Стек и чего не брать

| Слой | Чем | Где закреплено |
|---|---|---|
| Бэкенд | PHP, Laravel | `composer.lock` |
| Панель | Inertia + Vue 3; экраны из своих обёрток `resources/js/components/ui/App*.vue` | `package-lock.json` |
| Данные | PostgreSQL | `database/migrations/` |
| Тесты | Pest: Arch, Unit, Feature, Browser (Playwright) | `phpunit.xml` |
| Анализ, формат | PHPStan max, Pint | `phpstan.neon`, `pint.json` |

Не брать: готовый календарь-компонент (своя сетка слотов, `docs/decisions/003-svoya-setka.md`);
`JsonResource` (страница и экспорт едут через `Data`); очереди — до второй долгой операции.

## Где что лежит

Раскладка видна из дерева; здесь только то, что из него не выводится.

- `app/Domain/<Область>/` — `Bookings`, `Rooms`, `Shared`; внутри Actions, Data, Values, Events, Listeners, Policies, Models. Общего каталога моделей нет.
- `resources/js/components/ui/App*.vue` — примитивы без предметной области; доменные — в `components/<область>/`, страницы зеркалят домены.
- `database/seeders/DemoSeeder.php` — данные для разработки: три комнаты, две брони на завтра.

## Правила

| Правило | Проверка |

| контроллер не ходит в `DB` и не строит запросы | `tests/Arch/ArchitectureTest.php` |

## Ловушки

- `Slot` сравнивается через `equals()`: `==` на равных слотах даёт ложь из-за объектов дат (ловушка).
- Exclusion constraint не видит брони со статусом `cancelled`: условие `WHERE status <> 'cancelled'` живёт в миграции, не в коде (ловушка).
- `make:model` без пути кладёт класс в корень `App\`: только `make:model Domain/<Область>/Models/<Имя>` (ловушка).
- Всё из `lang/**/*.php` уезжает в публичный бандл фронта; закрытые тексты — в `lang/*.json` (ловушка).

Ошибся на факте, которого нет в коде, — предложи строку сюда тем же PR.

## Стиль решений

| Случай | Чем |
|---|---|
| граница: форма, консоль, экспорт | `extends Data` в `Data/` |
| значение с инвариантом (слот, почта) | `final readonly` в `Values/`, инвариант в конструкторе |
| что происходит | класс в `Actions/`, один на действие, `handle()` |
| ответ, который повторяется | класс в `app/Http/Responses/` |

## Git

- Ветка на задачу от `main`; PR до 400 строк диффа, иначе разбить и предложить порядок.
- Коммиты по-русски: что и зачем, не пересказ диффа.
- Описание PR: `## Что и зачем` · `## Заботы` · `## Решено без вас` · `## Не решено` · `## Нужны ваши руки` — каждый заполнен или «нет».
- Никогда: `reset --hard`, `checkout -- .`, `clean -fd`, `push --force`, `git add .`; агент не сливает PR; секрет в файл не попадает.
- В тестах, сидах и PR только выдуманные почты и имена.
- Узко значит узко: попутные рефакторинги, чужое форматирование, обновление зависимостей — не в этом PR; заметил — скажи.
