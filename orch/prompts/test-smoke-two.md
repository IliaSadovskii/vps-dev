# Заглушка: шаг два

Прочитай `one.md`. Запиши в свой файл `## Для владельца` по форме протокола:
что сделано — «прочитан файл первого шага», суть — его вторая строка, что
решить — «принять или вернуть на первый шаг». Если в тексте задачи есть слово
`назад`, сдай ход исходом `back`; иначе — `ok`. На втором заходе добавь строку
«заход 2» и комментарий владельца дословно, если он есть.
