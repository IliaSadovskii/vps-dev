# Сверка соглашений

Прочитай файл соглашений как агент, которому придётся доверять ему после сброса
памяти, и найди каждую строку, которую репозиторий не подтверждает.

**Читает:** `AGENTS.md` и `CLAUDE.md` на ветке задачи и их дифф против базовой
ветки; всё, что файл цитирует: манифесты, lock-файлы, CI, конфиги, файл за каждым
`путь:строка`; `conventions.md`; на втором заходе — свой прошлый
`conventions-review.md`.
**Пишет:** `conventions-review.md`. Файл соглашений не правишь, не коммитишь.
**Исходы:** `ok` — файл верен или неточности косметические, задача ждёт
владельца; `rework` — есть строки, делающие файл неверным, задача возвращается.

## Зачем

Автор писал файл, держа весь репозиторий в голове, и правдоподобная строка —
ровно та, которую он не перечитает: сдвинувшийся номер строки, версия из
документации вместо манифеста, каталог по привычке вместо `ls`. Ниже по цепочке
это никто не проверяет — копируют как факт. Ты другая сессия без интереса к
тексту: открой то, что он цитирует.

## Что проверять

Файл строка за строкой; проверяемое — проверить, не рассуждать о вероятности.

- Оба файла в нужной форме: содержимое в `AGENTS.md`, `CLAUDE.md` — ровно
  `@AGENTS.md`. Правила, оставшиеся только в `CLAUDE.md`, — блокирующая находка.
  Содержимое переезжало — дифф обоих против базы: ничего не потеряно и не
  переформулировано.
- Каждый `путь:строка`: файл есть, строка — то, что цитируется. Промах на
  несколько строк — находка.
- Каждая версия — против манифеста или lock-файла.
- Каждая команда существует там, где файл говорит.
- Каждый путь разрешается от корня этой рабочей копии.
- Каждое утверждение о раскладке: каталог есть, или файл прямо говорит, что его
  ещё нет.
- Правило, которое ничто не обеспечивает: либо названо, что обеспечивает, либо
  сказано «привычка», либо находка.
- Не удалено и не переписано лишнее — сравнение с базой.
- Длина около 150 строк; больше — на сколько и какой раздел резать.

Не проверяемое — приоритеты владельца, решения о будущем, вкус — не трогай.
Ты не второй автор.

## Исход

Есть хотя бы одна находка, делающая файл неверным, а не несовершенным, —
`orch done rework`. Иначе — `orch done ok`; что осталось косметическим — в
файле, владелец увидит.

## Форма `conventions-review.md`

`## Для владельца` первым по форме протокола: «Суть» — список находок по
строке: что написано, что на самом деле, где смотрела; или «находок нет» и что
открывала, чтобы убедиться.

- `## Находки` — те же с доказательствами, для автора.
- `## Что проверялось`
