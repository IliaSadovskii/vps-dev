# Правила фронта

Читать перед правкой `resources/js/**`. Ограничения, не описание.

- Сначала найти дизайн-систему проекта: токены, обёртки `components/ui/App*.vue`, экран с похожей задачей. Вторую палитру, radius, тень, шрифт не вводить.
- Страница живёт внутри `layouts/AppLayout.vue`: шапку, меню, тосты не рисует сама.
- У каждой страницы все состояния: loading, empty, error, success, sparse, dense, «нет прав». Скелетон повторяет раскладку.
- Ошибка поля стоит у поля; при ошибке форма не сбрасывается.
- Деструктивное действие — подтверждение или undo.
- Кнопка показывается по той же политике, что решает дверь на сервере.
- Фильтры, вкладка, страница — в URL: ссылку можно переслать.
- Проверять коротким, средним и абсурдно длинным текстом; на телефоне; с клавиатуры.
- Правишь экран — в PR есть браузерный тест на видимое поведение.
- UI, не открытый в браузере, не проверен.
