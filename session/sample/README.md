# Образец: «Переговорки»

Выдуманное приложение — бронирование переговорных комнат. Кода здесь нет,
только пять типов файлов в том виде, в каком скиллы должны их заводить в
настоящем проекте. Копируется форма, не стек и не предметная область.

| Файл | Тип |
|---|---|
| `AGENTS.md` | правила + продукт + каркас + оглавление; ≤ 150 строк без таблицы каркаса, таблица ≤ 40 |
| `docs/scenarios.md` | сквозные сценарии, один — где что-то идёт не так |
| `docs/rules/frontend.md` | правила одной области кода, ≤ 30 строк |
| `docs/decisions/` | журнал решений: README, шаблон, три записи |
| `docs/booking.md` | замысел подсистемы |
| `CLAUDE.md`, `docs/README.md` | служебные: одна строка и карта |
| `scripts/check-agents.sh` | сторож: размер и образцы каркаса |

Сторож на образце красный намеренно: путей из таблицы каркаса тут нет,
он проверяет проект, не образец.
