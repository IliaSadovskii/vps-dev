# Как вести задачу по цепочке

Перед первой задачей на Deep прогоните цепочку Conventions: она заведёт
или обновит `AGENTS.md` проекта, который все роли читают первым.

## Правила

1. Вы решаете в четырёх местах: запуск, ответы на вопросы, утверждение
   решения и плана, приёмка. Остальное едет само.
2. На воротах два действия. Вправо — «принимаю». Сообщение — «переделай»:
   карточка сама уедет назад, агент прочитает текст.
3. Агент возвращает работу назад только на один шаг и только один раз.
   Дальше идёт к вам с пометкой «не решено».
4. Руками назад — только на первую колонку блока. Сначала сообщение, потом
   перетаскивание.

## Цепочка

```text
 Понять        Backlog → Discovery → Scoping
 Выбрать       Research → Solution Synthesis → [Solution Approval]
 Спланировать  Planning ⇄ Plan Review → [Plan Approval]
 Сделать       Test Authoring → Implementation ⇄ Verification
 Проверить     Code Review → Security Review → Review Fixes ⇄ Fix Review
               ⇄ Final Verification → Documentation → Draft PR
 Принять       [Human Review] → Done
```

`[ ]` — ворота, карточка ждёт вас. `⇄` — агент может один раз вернуть.

## Ваши действия

| Где | Что делать |
|---|---|
| Backlog | Дописать условие. Перетащить на Discovery |
| Висит вопрос агента | Ответить в карточке. Не перетаскивать |
| Solution Approval | Прочитать `solution-synthesis.md`. Вправо или сообщение |
| Plan Approval | Прочитать План и `plan-review.md`. Вправо, или поправить План в интерфейсе и вправо, или сообщение |
| Human Review | Дождаться CI, прочитать diff, панель ревью и «Не решено» в PR. В Done или сообщение |
| Done | Переоткрыть — сообщение |
| Все остальные колонки | Ничего |

## Куда уходит сообщение

| Откуда | Куда |
|---|---|
| Solution Approval | Solution Synthesis |
| Plan Approval | Planning, потом снова Plan Review |
| Human Review, Done | Review Fixes, потом весь хвост до PR |

## Когда тащить руками

Только если сообщение попадёт не туда:

- нужны новые данные по вариантам → Research;
- план неверный, задача та же → Planning;
- нужен новый или другой тест → Test Authoring;
- задача поменялась → Scoping;
- не так оформлен PR → Draft PR.

В середину блока не тащить: роль рассчитывает на соседа слева.
Вперёд через колонки не тащить.

## Карточка застряла

Агент не работает, карточка не едет.

1. Прочитать последнее сообщение агента.
2. Написать «продолжай»: агент продолжит с той же памятью.
3. Нужен чистый перезапуск — перетащить в Backlog и обратно. В соседнюю
   колонку нельзя: стартует её агент.
