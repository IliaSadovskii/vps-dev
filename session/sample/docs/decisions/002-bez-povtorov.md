# 002. Повторяющихся броней нет

Дата: 2026-09-11 · Статус: принято

**Решено.** Бронь — один непрерывный слот. «Каждый вторник» не поддерживается.

**Почему.** Повтор усложняет пересечения (серия против одиночной брони), отмену (одну или все) и экспорт — ради случая, который по опросу нужен двум людям из сорока.

**Отвергли.** Серия как родитель одиночных броней: пересечения решаются, но отмена серии с частичными исключениями тянет отдельный экран.

**Где.** `docs/booking.md`, `docs/scenarios.md`.
