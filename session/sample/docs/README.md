# Документация

Правда — код и тесты; документы говорят, где искать и почему так решили.
Меняются тем же PR, что и код.

| Где | Что | Когда читать |
|---|---|---|
| `../AGENTS.md` | правила, продукт, оглавление забот каркаса, оглавление документов | каждую сессию, читается сам |
| `skeleton.md` | каркас: забота → образец → правило → проверка | перед предложением фичи — строки задетых забот |
| `scenarios.md` | сквозные сценарии на настоящих именах | проверка полноты каркаса и описания продукта |
| `rules/frontend.md` | правила фронта | перед правкой `resources/js/**` |
| `booking.md` | замысел подсистемы броней | перед правкой броней и слотов |
| `decisions/` | журнал решений, только дописывается | «почему именно так» |

Чего здесь нет: описания того, как код работает сейчас. Это код и `git log`.
